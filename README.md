# Expense Manager

Aplicación web desarrollada con React y Firebase para la gestión de proyectos y gastos compartidos.

## Características

- Registro e inicio de sesión con Firebase Authentication
- Rutas protegidas
- Gestión de proyectos
- Gestión de participantes
- Gestión de gastos
- Resumen de balances por participante
- Base de datos en Firebase Firestore

## Tecnologías utilizadas

- React
- React Router
- Firebase Authentication
- Firebase Firestore
- Vite
